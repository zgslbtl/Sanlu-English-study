# Paper Cards

这个目录用于给固定语料池中的每篇论文建立单独卡片。

## PDF 位置

下载好的论文 PDF 请统一放在：

- `data/english/corpus/papers/pdf/`

推荐命名方式：

- `P01_second_mind.pdf`
- `P02_sensemaking_llm_outputs.pdf`
- `P06_musebench.pdf`

推荐文件名：

- `P01.md`
- `P02.md`

推荐内容：

1. 标题
2. 网页链接
3. 本地 PDF 路径
3. 所属类别
4. 为什么入选
5. 建议优先读的段落
6. 可反复复用的关键词
7. 可延伸出的听说写任务
